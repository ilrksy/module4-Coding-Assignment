## 2023-10-26 - Semantic landmarks and keyboard hints
**Learning:** Adding a `<main>` tag helps screen readers easily find the primary content on a page, especially when it is minimal. `<kbd>` tags provide immediate semantic meaning and default browser styling for keyboard shortcuts, making instructions clearer.
**Action:** Always wrap primary content in `<main>` tags and use `<kbd>` for keyboard shortcuts in instructional text to improve both accessibility and visual clarity.
