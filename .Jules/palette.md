## 2024-03-24 - Semantic HTML for Keyboard Shortcuts
**Learning:** Using the `<kbd>` tag to mark up keyboard shortcuts (like `F12` or `Cmd+Option+J`) improves accessibility and allows user agents (or CSS) to style them distinctly, making instructions clearer for users who rely on keyboard navigation.
**Action:** Consistently use the `<kbd>` tag when providing keyboard instructions in UI text to enhance both visual distinction and semantic meaning.
