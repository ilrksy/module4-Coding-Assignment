## 2024-05-18 - Semantic Landmarks and Mobile Viewports
**Learning:** Vanilla HTML applications often omit fundamental a11y landmarks like `<main>` and mobile responsiveness `<meta name="viewport">` tags. Adding them ensures screen readers can identify the primary content area and text scales appropriately on smaller screens.
**Action:** When inspecting vanilla web apps, prioritize checking the `<head>` for viewport tags and the `<body>` for semantic landmark tags.
